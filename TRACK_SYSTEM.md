# 🎵 Система автоматической обработки музыкальных треков

## 📋 Описание
Полнофункциональная система для музыкального онлайн-плеера, которая автоматически обрабатывает загружаемые MP3 файлы, извлекает метаданные и интегрирует их в базу данных.

---

## ✨ Основные возможности

### 🎯 Автоматическое извлечение данных
- **🆔 Генерация уникального ID** — каждый трек получает уникальный MongoDB ObjectId
- **⏱️ Определение длительности** — автоматически извлекается из MP3 файла
- **📝 Автоматическое название** — подставляется из имени файла, если не указано вручную
- **📊 Статистика** — количество прослушиваний (по умолчанию 0)
- **💾 Сохранение пути** — хранится полный путь к аудиофайлу

### 🎨 Отображение информации
- Все данные трека отображаются в списке песен
- Показываются: название, исполнитель, длительность, количество прослушиваний, ID

## 🔧 Техническая архитектура

### Backend (Node.js + Express)

**Установленные зависимости:**
```json
{
  "express": "^5.1.0",
  "mongoose": "^8.18.2",
  "multer": "^2.0.2",
  "music-metadata": "^8.x.x",    // ← НОВОЕ: Извлечение метаданных MP3
  "cors": "^2.8.5",
  "jsonwebtoken": "^9.0.2",
  "bcryptjs": "^3.0.2"
}
```

**Эндпоинт загрузки:** `POST /api/upload`

```javascript
// Параметры запроса:
- track: FormData file (MP3 файл)
- title: string (опционально - если пусто, берётся из имени файла)
- artist: string (опционально - если пусто, становится "Unknown Artist")

// Возвращаемые данные:
{
  "_id": "ObjectId",           // Уникальный ID трека
  "title": "Название трека",   // Автозаполненное или введённое
  "artist": "Исполнитель",     // Автозаполненное или введённое
  "url": "http://localhost:5000/music/...",  // Путь к файлу
  "cover": "http://localhost:5000/images/default-cover.jpg",
  "plays": 0,                  // Количество прослушиваний (по умолчанию 0)
  "duration": 240,             // Длительность в секундах (автоматически)
  "message": "Трек успешно загружен и обработан"
}
```

### Frontend (React)

**Компонент UploadPage.js:**
- ✅ Предпросмотр информации о файле (размер, автоматическое название)
- ✅ Автоматическое заполнение названия из имени файла
- ✅ Отправка формы с файлом на backend
- ✅ Показ статуса загрузки и извлечения данных
- ✅ Перенаправление на список песен после успешной загрузки

**Компонент SongsPage.js:**
- ✅ Отображение всех треков с полной информацией
- ✅ Показ длительности трека (формат MM:SS)
- ✅ Показ количества прослушиваний (с форматированием K, M)
- ✅ Показ ID трека (первые 8 символов с "...")

## 📊 Схема данных MongoDB

```javascript
{
  "_id": ObjectId,          // Автоматический уникальный ID
  "title": String,          // Название трека
  "artist": String,         // Исполнитель
  "url": String,           // Путь к MP3 файлу
  "cover": String,         // Путь к обложке
  "plays": Number,         // Количество прослушиваний
  "duration": Number       // Длительность в секундах
}
```

## 🚀 Как это работает

### Процесс загрузки трека:

```
1. Пользователь выбирает MP3 файл
   ↓
2. Фронтенд автоматически заполняет название из имени файла
   ↓
3. Отправляется запрос на backend
   ↓
4. Backend получает MP3 файл
   ↓
5. Использует music-metadata для извлечения длительности
   ↓
6. Генерируется уникальный MongoDB ObjectId
   ↓
7. Трек сохраняется в базу данных
   ↓
8. Фронтенд получает все данные трека
   ↓
9. Трек отображается в списке со всеми метаданными
```

### Через API (curl)
```bash

  -H "Authorization: Bearer YOUR_TOKEN" \
```

## 🐛 Решение проблем

### Проблема: "Не удалось извлечь метаданные"
**Решение:** MP3 файл может быть повреждён. Проверьте, что файл открывается в плеере.

### Проблема: Пустое название трека
**Решение:** Если файл без расширения или с особыми символами, название может не заполниться. Введите вручную.

### Проблема: Длительность показывает 0
**Решение:** Попробуйте пересохранить MP3 файл в другом формате (320 kbps, 128 kbps и т.д.).
