# ⚡ Быстрый справочник - Система обработки треков

## 🎯 За 30 секунд

1. **Установить зависимости:** `npm install music-metadata` (в backend)
2. **Выбрать MP3:** Перейти на "Загрузить новый трек"
3. **Система делает автоматически:**
   - ✅ Определяет длительность
   - ✅ Генерирует уникальный ID
   - ✅ Заполняет название из имени файла
   - ✅ Устанавливает 0 прослушиваний
   - ✅ Сохраняет путь к файлу
4. **Смотреть результат:** В списке "Все песни"

---

## 📦 Установка

### Backend
```bash
cd backend
npm install music-metadata
```

Готово! Всё работает.

## 🔧 Значения по умолчанию

| Параметр | Значение | Откуда берется |
|----------|----------|---|
| ID | ObjectId | MongoDB (автоматический) |
| Название | Из файла или введённое | Имя файла без расширения |
| Исполнитель | "Unknown Artist" | Если не указан |
| Длительность | Из MP3 | Автоматически извлекается |
| Прослушивания | 0 | По умолчанию |
| Путь | /music/{filename} | public/music/ папка |

## 🐛 Частые проблемы

| Проблема | Решение |
|----------|---------|
| "Не удалось извлечь метаданные" | Файл повреждён, переконвертируйте |
| Длительность 0 | Используйте другой MP3 |
| Нет названия | Введите вручную или переименуйте файл |
| Ошибка 401 | Проверьте токен авторизации |
