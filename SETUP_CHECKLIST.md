## 🧪 Шаг 6: Тестирование функциональности

### Тест 1: Авторизация
- [ ] Откройте `http://localhost:3000`
- [ ] Авторизуйтесь или зарегистрируйтесь
- [ ] Проверьте, что токен сохранён

### Тест 2: Загрузка трека
1. [ ] Нажмите "Загрузить новый трек"
2. [ ] Выберите MP3 файл
3. [ ] Проверьте автоматическое заполнение названия
4. [ ] Проверьте отображение информации о файле:
   - [ ] Название файла
   - [ ] Размер файла
   - [ ] Автоматическое название
5. [ ] Добавьте исполнителя (опционально)
6. [ ] Нажмите "✨ Загрузить трек"

### Тест 3: Проверка результата
1. [ ] Дождитесь сообщения об успехе
2. [ ] Перейдите на "Все песни"
3. [ ] Проверьте, что трек появился в списке
4. [ ] Проверьте отображение метаданных:
   - [ ] Название трека
   - [ ] Исполнитель
   - [ ] ⏱️ Длительность (в формате MM:SS)
   - [ ] 👁️ Количество прослушиваний (0)
   - [ ] ID трека (первые 8 символов)

### Тест 4: Проверка в браузере (DevTools)
1. [ ] F12 → Network
2. [ ] Загрузите трек
3. [ ] Найдите запрос POST к `/api/upload`
4. [ ] Статус: **201**
5. [ ] Ответ содержит:
   - [ ] `_id`
   - [ ] `title`
   - [ ] `duration` (не 0)
   - [ ] `plays: 0`
   - [ ] `url`

### Тест 5: Проверка файла на сервере
```bash
# Windows
dir backend\public\music\

# Linux/Mac
ls -la backend/public/music/
```

Должны увидеть:
- [ ] MP3 файл с временной меткой в названии

## 🐛 Шаг 8: Диагностика проблем

### Проблема: "Ошибка при загрузке файла"
- [ ] Проверьте консоль backend (есть ли ошибка?)
- [ ] Проверьте, что MP3 файл валидный
- [ ] Проверьте права доступа на папку `public/music/`

### Проблема: "Длительность 0"
- [ ] Попробуйте другой MP3 файл
- [ ] Проверьте консоль: "Не удалось извлечь метаданные"
- [ ] Убедитесь, что music-metadata установлена

### Проблема: "Название не заполнилось"
- [ ] Проверьте имя файла (должны быть символы a-z, 0-9, пробелы)
- [ ] Введите название вручную
- [ ] Переименуйте файл и попробуйте снова

### Проблема: Файл не сохраняется
- [ ] Проверьте папку backend/public/music/ существует
- [ ] Проверьте права доступа: `chmod 755 backend/public/music/`
- [ ] Проверьте свободное место на диске

### Проблема: MongoDB не подключена
- [ ] Проверьте, что MongoDB запущена
- [ ] Проверьте Connection String в server.js
- [ ] Проверьте пароль и логин для MongoDB
