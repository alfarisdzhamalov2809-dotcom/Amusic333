# Git LFS Setup Guide

## Prerequisites
```
git --version          # Ensure Git 2.13+
git lfs --version      # Verify Git LFS is installed
```

## Initialization Commands

### Step 1: Initialize Git LFS
```powershell
# Install Git LFS (if not already installed)
# For Windows: via Chocolatey
choco install git-lfs

# OR download from: https://git-lfs.github.com/

# Initialize Git LFS in the repository
git lfs install

# Verify installation
git lfs version
```

### Step 2: Track Binary Media Files
```powershell
# Execute in project root directory
# Audio files
git lfs track "*.mp3"
git lfs track "*.wav"
git lfs track "*.flac"

# Image files
git lfs track "*.png"
git lfs track "*.jpg"
git lfs track "*.jpeg"
git lfs track "*.gif"
git lfs track "*.svg"

# Video files (if applicable)
git lfs track "*.mp4"
git lfs track "*.mov"
```

### Step 3: Commit Configuration
```powershell
# Stage the .gitattributes file (auto-generated by lfs track)
git add .gitattributes

# Verify tracking configuration
git lfs track

# Commit LFS configuration
git commit -m "chore: initialize Git LFS with media file tracking"
```

## Migrate Existing Large Files to LFS

```powershell
# Migrate already-committed large files
git lfs migrate import --include="*.mp3,*.png,*.jpg,*.jpeg,*.svg"

# Force push if history has changed
git push --force-with-lease origin main
```

## Verification Commands

```powershell
# List all tracked files
git lfs ls-files

# Check file status
git status

# Monitor LFS storage usage
git lfs logs --last 10
```

## Clone Repository with LFS

```powershell
# Standard clone automatically handles LFS
git clone <repository-url>

# Partial clone with pointer files only (advanced)
git clone --filter=blob:none <repository-url>
git lfs pull
```

## Daily Workflow

```powershell
# Normal operations remain unchanged
git add .
git commit -m "Add media assets"
git push origin main

# LFS objects are automatically managed
# No special commands needed during typical workflow
```

## Configuration Verification

```powershell
# View .gitattributes content
cat .gitattributes

# List LFS tracked patterns
git config --list | grep lfs

# Check current LFS settings
git lfs env
```

## Troubleshooting

```powershell
# If pointer files appear instead of actual files
git lfs pull

# Verify LFS object integrity
git lfs fsck

# Force LFS authentication (if behind corporate proxy)
git lfs install --local --force
```

---

**CRITICAL**: Commit `.gitattributes` to the repository immediately after initializing LFS.
All team members must run `git lfs install` after cloning the repository.
